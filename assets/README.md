# Umbra icon provenance

`umbra.ico` is the unchanged AsiaHorse Umbra icon from the supported
**V3.5.5_09.03** installation:

```text
img/ARGB/0005YZM/0005YZM_LOGO.ico
```

It is used for the Windows setup executable and its window. The source archive
retains this single brand asset so the setup can be rebuilt with the same icon.
